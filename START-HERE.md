# Install and run in 10 steps

1. Install **Blender 5.2 LTS**.
2. Download **Blender-Video-Input-0.3.0-beta.zip** from this repository's Releases. Keep it compressed.
3. Open **Preferences > Add-ons > Install from Disk**.
4. Select the ZIP and enable **Live Video Input**.
5. Select a mesh object, such as Blender's default cube.
6. Press **N > Video Input > Apply to selected objects**.
7. Switch the viewport to **Material Preview**.
8. Choose **Test pattern > Connect** to test it, then **Disconnect**.
9. Enable your sender using the [Resolume, TouchDesigner or OBS guide](SENDING-VIDEO.md).
10. In Blender, choose the matching input, refresh **Source**, select your sender, and **Connect**.

Click **Disconnect** when finished. For help: **Advanced and troubleshooting > Export support log**.
