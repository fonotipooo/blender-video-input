# Reporting a problem

Open an issue with:

- Operating system and processor architecture
- Blender and add-on versions
- Sending app/version and input protocol
- Expected and actual behavior
- Steps to reproduce
- Whether the built-in Test pattern works
- Received and preview dimensions
- Relevant error message or a reviewed support-log excerpt

Export logs under **Video Input > Advanced and troubleshooting > Export support log**. Review before sharing: source names and machine/network details can appear. Do not attach working scenes, project media, passwords, credentials or unrelated personal files.

Mac/Linux testers should record discovery, changing frames, disconnect/reconnect and protocol switching separately. A discoverable source alone does not verify reception.
